编制日期：2026-10-06。以下规模是初始工作预算，不是学校规定或已完成成果。已确认：学生为几何算法实习生，经常使用 OpenCascade，使用 Python 开发，每周可投入 15 小时；设备为 ThinkPad T14p Gen3 2025，内存 64 GB，优先本地运行，API 总预算约 50 元人民币。

## 1. 研究定位

研究对象是 NURBS 曲面建模、曲面恢复与相关故障诊断中的技术知识。这里的“恢复”包括从采样数据拟合曲面、处理模型缺陷时所需的知识支持；本阶段不承诺实现新的曲面重建算法。按既有决策记录，导师已接受这一知识检索边界；后续如有变更，再记录新的要求。

核心问题：面对专业同义词、缩写、多语言名称以及以症状描述的查询，显式术语和领域关系能否改善检索结果，并为回答提供可核查的证据？

三个研究问题：

- RQ1：关键词检索、向量检索及混合检索，在不同问题类别上的表现如何？
- RQ2：同义词及受控术语扩展相对于相同基础检索器，是否改善排序质量和相关材料覆盖率？
- RQ3：“症状—可能原因—检查方法”关系相对于单纯术语扩展，在哪些问题上有帮助，在哪些问题上引入噪声？

预期贡献是可追溯的小型领域语料、带证据的术语及关系模型、可重复运行的检索原型和对照实验。不得将调用现有 LLM 或使用向量数据库本身写成创新点，也不得提前宣称方法优于基线。

## 2. 研究边界和最低交付

覆盖五类问题：术语定义和 API 定位、B 样条/NURBS 表示、曲面拟合与近似、边界与连续性、容差与有效性诊断。明确区分底层几何曲面和 B-Rep 中带边界的面，避免把拓扑问题都归因于 NURBS 参数。

默认实验主语言为俄语，语料允许英语和俄语；中文用于学习说明和交互辅助。若评估俄中跨语言检索，必须另外标记语言与翻译策略，不与领域本体的效果混为一谈。

## 5. 实现路线

推荐先用 Python、JSONL/JSON、BM25 和一个多语言嵌入模型实现本地检索。小语料可直接进行余弦相似度排序；向量数据库、图数据库不是必需条件。关系用类型化边表和一跳遍历即可起步。

资源策略：BM25、本体遍历、评估和嵌入均优先本地运行。首个嵌入候选为 `intfloat/multilingual-e5-small`，先核实模型许可、输入前缀要求与俄英专业查询效果，再固定版本；CPU 可作为起步路径。64 GB 系统内存不代表具有大显存，不据此承诺本地大模型吞吐。回答层可先测试小型量化本地模型，实际规模依据显卡和延迟决定。

预算规则：不将付费 API 用于批量嵌入、自动构造全部语料或主检索实验。约 50 元视为总预算上限；预留至少 10 元，只在必要的少量回答案例使用最多约 40 元。首次调用前按所选服务的实际价格、输入输出 token 和调用数估算，程序设置累计支出停止条件；价格和汇率未核实时不能给出可调用次数。当前尚未发生任何模型费用。

建议模块：`ingest`（登记和抽取）→ `chunk`（结构化切分）→ `index`（关键词/向量）→ `retrieve`（混合及增强检索）→ `evaluate`（统一指标）→ `answer`（依据证据回答）。目前已在 `src/nurbs_knowledge/` 建立对应空包骨架，尚无业务实现。

混合检索采用可记录配置的排序融合方法，例如 RRF。所有增强方法基于相同的混合检索器。关系检索通过概念链接、限定关系类型的一跳遍历和证据片段回取实现。未获证据支持的诊断边不进入正式检索索引。

回答层固定提示词，要求来源引用、说明证据不足，并把“可能原因”保持为可能性。先验证检索效果，再检查回答是否忠于证据。仅使用公开且允许处理的资料进行必要的 API 验证；实习中的内部问题先抽象为不含敏感信息的场景。当前不锁定厂商、不安装大型模型。

## 6. 论文与报告写作结构

建议俄文章节：

1. Введение：问题背景、对象、目标、任务、范围。
2. Обзор методов поиска знаний и RAG：方法、已有工作、差距。
3. Формирование корпуса и тезауруса предметной области：来源、概念、关系、质量控制。
4. Архитектура и реализация средств поиска：管线、配置、追溯机制。
5. Экспериментальное исследование：问题集、对照、指标、结果、误差和局限。
6. Заключение：回答研究问题，陈述已完成工作和后续方向。

学校模板优先。文献阅读从 BM25、句向量、多语言检索、RAG、查询扩展、知识图谱/本体检索，以及 NURBS 与 CAD 几何有效性资料展开。每篇写清问题、方法、证据、局限和与本课题的联系，而非只复述摘要。

实践能力对应：УК-1.1 用来源登记和综述体现；УК-1.2 用批判性比较和语料筛选体现；УК-1.3 用受控实验及误差分析体现；ПКС-2.2 用模块化原型、数据结构和可复现运行体现。
