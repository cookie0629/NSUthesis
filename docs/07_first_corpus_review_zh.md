## 已知风险与处理

- API 注释不是完整理论教材，不将其作为所有 NURBS 性质的唯一理论来源。
- `GeomAbs_Shape` 原文部分描述在曲线和曲面之间切换，保留原文和限定，不擅自改写为普适曲面定理；特别是 G2 的描述需要结合上下文核对。
- BRepCheck_Analyzer 部分容差检查项标为 NYI，保留这一限制，不能汇报为已实现全面容差诊断。
- 获取 `Geom_Surface` 不等同于获取完整裁剪 B-Rep 面；查询涉及面与边界时可能需要多个片段。
- 本轮仅索引注释正文，API 标识符有时只出现在标题或签名中，因此纯 API 名称查询可能漏检。暂不通过修改演示题或加入同义词来隐藏这一限制。
- 六个单元全部为英文并来自同一产品，不能推断俄英跨语言表现或其他 CAD 软件表现。

十道英文开发题均为助手设计的合成场景，每类两题，每题有家族 ID 和证据需求，均标记 `pending_human_review`。题目已用于开发演示，永远不能据此宣称独立测试效果。
