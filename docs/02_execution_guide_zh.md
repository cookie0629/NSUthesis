# 执行与学习指南

## 需要掌握的最少几何知识

- NURBS 的次数、基函数、控制点、权重和节点向量分别起什么作用；控制点一般不是曲面上的采样点。
- 参数域 `(u, v)` 与三维位置不同；参数曲线和三维边曲线的表示不可混淆。
- 底层曲面、裁剪边界、B-Rep 面及其拓扑关系是不同层次。
- 位置连续、切向连续、曲率连续以及参数连续/几何连续的区别。
- 拟合误差、输入数据噪声、几何容差和模型有效性是不同问题。

暂不要求从零推导完整 NURBS 理论。

## 需要掌握的最少检索知识

- BM25 根据词项匹配排序；同义词、俄语词形和缩写会影响命中。
- 向量检索根据嵌入相似度排序；必须实测多语言和专业术语表现。
- 混合检索融合两类候选；融合配置也属于需要冻结的实验条件。
- RAG 包含检索和根据证据生成回答两个环节；答案流畅不能证明检索更好。
- 本体/词表用显式概念和类型化关系表达知识；词语相近不能自动视为“可能原因”。

练习方式：对同一个开发问题，人工查看关键词结果和向量结果各前五条，记下为何相关/不相关。先理解错误，再实现扩展。
