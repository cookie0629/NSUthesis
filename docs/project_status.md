## 当前结果与限制

成功案例：节点重数与连续性的相关段落位列首位。失败/不足案例：面的底层曲面与容差查询未在前五条取得完整证据；纯俄语查询无匹配。十道题均有词项匹配，不等于十题都相关或答对。

本轮没有人工相关性标签、nDCG 等正式指标、向量模型、关系检索或生成答案。语料规模仅用于验证流程；尚未达到原研究计划最低正式语料规模。没有模型下载或付费 API 调用。

原 Python 3.13 注册路径失效；官方安装器受旧安装记录影响，未在指定目录提供解释器。项目最终采用官方 NuGet Python 3.13.17 包直接解包，实际可用环境以 `.venv` 为准。
