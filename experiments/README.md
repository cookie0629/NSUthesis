# 实验与可复现证据

当前没有实验运行、指标、标签或结果图。规划中的六组方法尚未实现。

- `protocols/`：开发完成后的冻结协议、配置和数据哈希；目前仅保留目录。
- `runs/`：每次运行新建一个目录，保存实际配置、环境、数据哈希、逐查询结果、人工标注、指标和日志。
- `figures/`：从真实结果生成的图表，注明 run_id 与重算方法。

未来一次运行建议包括以下文件；这些是约定，尚未生成：

```text
runs/<run_id>/
├── manifest.json         时间、环境、代码/数据/配置版本、哈希与随机种子
├── config.json           实际执行配置
├── retrieval.jsonl       查询、扩展、路径、排名、得分、耗时与错误
├── judgments.jsonl       人工标签、依据、标注者、复核记录
├── metrics.json          逐问题、均值、分组、配对差值及区间
└── run.log               运行日志
```

具体字段和指标服从 [检索实验规范](../docs/03_evaluation_protocol_zh.md)。正式评估前落实独立测试题的保管和冻结安排；开发阶段不得为补齐此目录读取测试内容。早期演示放在 `reports/demos/` 并明确标注开发演示。
