# 周报与阶段汇报

汇报与开发同步推进。2026-10-22 已有真实 BM25 开发演示及第一轮汇报草稿.

| 目录           | 用途                                                                               |
| ------------ | -------------------------------------------------------------------------------- |
| `weekly/`    | 每周记录真实产物、核查方式、问题和周验收目标                                                           |
| `stages/`    | 导师或学校阶段报告、短讲稿；默认俄文，待核对实际要求                                                       |
| `slides/`    | 后续汇报幻灯片；目前为空                                                                     |
| `demos/`     | 真实命令行运行、JSON 结果、哈希与验证记录；本轮没有界面截图                                                 |
| `templates/` | [周报模板](templates/weekly_template_zh.md)与[阶段报告模板](templates/stage_template_zh.md) |

本次可用材料：

- [2026-10-22 实施周报](weekly/2026-10-22_weekly_zh.md)：环境、语料、程序、写作及局限。
- [约五分钟俄文汇报稿](stages/2026-10-22_bm25_brief_ru.md)：包含实际案例，待审阅。
- [最终开发演示及验证证据](demos/README.md)：不要混用早期运行的得分。

- [2026-10-06 周报草稿](weekly/2026-10-06_weekly_zh.md)：目录整理和前置条件核对。
- [初始阶段俄文汇报讲稿](stages/2026-10-06_setup_brief_ru.md)：解释目标、方法设计、实际进度和下一步。是供学生理解、核对后使用的草稿，尚未向导师提交。

阶段交付与日期统一维护在 [项目状态](../docs/project_status.md)。准备汇报时先确定对象、语言、时长、格式，再从周报和证据文件中选取内容；涉及实验数字必须能回溯到运行记录。
