# 参考资料

- `school/`：学校原始模板和要求。先填写[要求登记](school/requirements.md)。
- `literature/`：许可允许保存的文献与原始材料；目前为空。
- `notes/`：使用[阅读笔记模板](notes/reading_template_zh.md)记录阅读收获与核查状态。
- `bibliography.bib`：已核实参考文献的统一书目源，目前没有条目。

研究计划中的 BM25、Sentence-BERT、RAG、NURBS 等名称是检索线索，不是已审核的参考文献。先核对题名、作者、年份、版本和定位，再加入正式书目。用于检索系统的资料还须登记到 `data/sources/registry.jsonl` 并处理许可。
