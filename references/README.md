# 参考资料

- `school/`：学校原始模板和要求。先填写[要求登记](school/requirements.md)。
- `literature/verification/`：OCCT 许可、固定提交与下载清单、Crossref/ACL/NeurIPS 书目与摘要核验材料，以及 Python 运行时来源记录。
- `notes/`：使用[阅读笔记模板](notes/reading_template_zh.md)记录阅读收获与核查状态。
- `bibliography.bib`：四条核实书目：BM25、Sentence-BERT、RAG 以及 OCCT 7.9.0 来源。没有把公开摘要核验写成全文精读。

本轮中文笔记：[BM25](BM25_zh.md)、[Sentence-BERT](Sentence-BERT_zh.md)、[RAG](RAG_zh.md)。其他 NURBS、查询扩展与本体检索文献仍是待核实线索。用于检索系统的资料还须登记到 `data/sources/registry.jsonl` 并处理许可；方法论文的摘要页面没有作为本轮领域语料。
