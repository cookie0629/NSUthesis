# 论文写作

正文默认俄文，当前只有[章节提纲](chapters/00_outline_ru.md)，没有完成的论文章节或实验结论。先用 Markdown 持续积累内容，拿到学校模板后再确定正式排版与导出格式。

- `chapters/`：提纲和正文草稿。后续按 `01_introduction_ru.md`、`02_review_ru.md` 等顺序拆分。
- `assets/`：正文需要的图表与示意图；每项标明来源或对应实验。
- `exports/`：学校格式的导出版本；目前为空。
- 统一文献库：`references/bibliography.bib`；学校要求：`references/school/requirements.md`。

每段结果都要能对应实验记录；没有运行的数据留待补写。导师或学校的模板优先于当前建议章节结构。阶段报告保存在 `reports/stages/`，不与毕业论文正文混为同一交付物。
